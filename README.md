# Browser Roguelike Prototype

This repository contains a minimal top-down roguelike prototype that runs entirely in the browser. It demonstrates:

- Procedurally carved dungeon layout rendered to an HTML canvas
- Keyboard input with arrow keys or WASD controls
- Simple activity log for player feedback

## Getting started

Open `index.html` in a modern browser (Chrome, Firefox, or Edge) to try the prototype. Use the arrow keys or WASD to move the explorer around the dungeon.

No build tools are required.
